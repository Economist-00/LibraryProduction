Overview

本プロジェクトは、業務系 Web アプリケーションを一人で設計・実装・動作確認まで完結させることを目的として開発した、社内図書館向け管理システムです。
単なる CRUD 実装に留まらず、設計・データ整合性・運用を意識した実装を重視しています。

Architecture & Design
1. 設計主導の開発プロセス

実装前に ER 図・画面遷移図・テーブル定義書を作成

データ構造と機能要件を明確化したうえで開発を開始

実務を想定し、後から仕様変更・機能追加がしやすい構成を意識

→ 設計 → 実装 → 動作確認の一連の流れを経験

2. データベース設計（正規化・拡張性）

書籍マスタ情報、冊子単位の在庫、貸出履歴を分離して管理

単純な状態フラグ管理ではなく、貸出履歴として状態を保持

過去の貸出状況の追跡

利用履歴の集計・分析が可能

将来的な予約機能や利用統計の追加を考慮した設計

Implementation Details
3. Django フレームワークの適切な活用

Django ORM を用いた安全で可読性の高い DB 操作

認証・フォーム・モデルの標準機能を活用しつつ、
業務ロジックは自前で実装

MTV 構造を意識し、責務を分離した構成

4. 外部 API（ISBN）連携

ISBN を用いた書誌情報の自動取得機能を実装

API レスポンスが取得できないケースを想定し、

データ欠損時の分岐処理

手動入力によるフォールバック

業務が止まらない設計を意識

5. データ整合性・バリデーション

在庫が存在しない書籍は貸出不可

同一冊子の重複貸出を防止

URL 直接アクセスなどを考慮し、サーバーサイドで必ず状態検証

クライアント側の入力を信用しない設計
